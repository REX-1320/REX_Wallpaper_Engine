# DEPRECATED

This project has been merged into `rex-core/`.

All source files moved to `rex-core/src/`:
- `wallpaper/` — wallpaper engine module
- `graphics/` — shared graphics (renderer, compositor, animation, effects)
- `core/` — scheduler, sandbox
- `ipc/` — IPC server

See `rex-core/CMakeLists.txt` for the unified build.

**Do not add new code here.** Build from `rex-core/build/` instead.
