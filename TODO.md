- [x] **Video stutter root-caused (FOUND 2026-10-11; CLOSED 2026-10-14 after 4 display-rate experiments + 2 10× repeatability runs + per-frame correlation + a temporary decode probe).** THREE SEPARATE mechanisms, none of them cadence:

Model: each playback locks submit phase onto the refresh grid at startup; mid-window lock (AE p50 ≈ +0.1) leaves margin → clean run (0.5–0.7); lock 1 ms before deadline (AE p50 ≈ −1.0) → **no margin → slips every frame for the whole run (7.8–8.6, stable)**. Per-frame correlation: AE top-5% frames had **identical** mean GPU (13.23 vs 13.65 ms) and submit to the rest — **GPU saturation DISPROVED as the cause**.
